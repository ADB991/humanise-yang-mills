# A generalized free field as a witness of the public statement (in progress)

**Target.** `theorem YangMills.jointExistence_of_freeField : YangMills.JointExistence` (`Main.lean`), proved from a scalar generalized free field with no use of `Solution` or `YangMills.constructed`. The import closure is the three public files, Mathlib, `../Adequacy.lean` and `../GroupIndependence.lean` (for `haarFamily` only). This is the formalisation of finding M4 of the G01 review (issue #162). If completed it shows that the public statement is satisfied by a free-type field for every simple group.

**Status (13 November 2026, phase 1): not finished.** `Main.lean` is complete and contains no `sorry`: it derives the target from named lemmas in the other files. Of the 75 lemmas of the task table, 27 are proved and verified and 48 are still `sorry` in the stating files, so `#print axioms YangMills.jointExistence_of_freeField` currently reports `[propext, sorryAx, Classical.choice, Quot.sound]`. Nothing here should be cited as a proof yet.

**Design** (`DESIGN.md`). One scalar field with one-particle measure `weight(p) dp`, `weight = (p²)²/log²(e+p²)` on the forward cone (no Bessel functions). Labels are the free vector space on multisets of derivative multi-indices (Wick monomials), filtered by grade. The Hilbert space is the closed span of explicit word vectors inside an unsymmetrised direct sum of `L²` spaces; `Host.reconstruct` turns a host with good word vectors into a `WightmanTheory` with `Axioms`. Correlations, their continuation and the Wightman functions are explicit sums over matchings. The trace field is a multiple of the basic field, normalised so that the limit in `TraceTest.shortDistance` is exactly `3 dim 𝔤/π⁴` (the constant `384π` of the two-point function is proved in `Proofs/SrAsymptotic.lean`). The final witness is `Adequacy.hier` applied to this seed hierarchy, so the lattice clause is met as in `../Adequacy.lean`.

**Files.** `Labels`, `TwoPoint`, `Wick`, `Hierarchy`, `Fock`, `Symmetry`: definitions, no `sorry`. `Analytic`, `Reconstruction`, `Theory`, `Continuation`, `OPE`: lemma statements, with assembly proofs of `exists_fockHost`, `exists_wightmanTheory`, `exists_ope_coefficient`. `Trace`: complete. `Proofs/`: proofs already wired into the build. `Work/`: one file per proved lemma (or group), proving a primed copy `NAME'` of the statement; each imports the stating module, so it cannot yet be imported back without a cycle. A final consolidation will replace every `sorry` by its proof. `TASKS.md`: the open lemmas with dependencies and difficulty. `Check/check_conventions.py`: numeric tests of the sign and normalisation conventions. `SHA256SUMS`: hashes of all Lean files and the lakefile.

**How to check.** In a directory with the three public files, `lean-toolchain`, `lake-manifest.json`, `../Adequacy.lean`, `../GroupIndependence.lean`, `../lakefile.toml` and this directory: `lake exe cache get`, then `lake build` (8,678 jobs, `sorry` warnings only). A `Work/` file is checked with `lake env lean FreeField/Work/NAME.lean`; to confirm that a primed theorem has the type of the original, append `example := (@NAME' : type_of% @NAME)`.

**Who did what.** Design, definitions, skeleton and task split: a Claude agent (Fable). Review of the architecture and of the truth of every lemma statement, before proof work started: four read-only GPT-6 Astra passes (`reviews/`; no blocker, all statements judged true, one proof outline repaired by a directed-cut argument). Proofs in `Proofs/` and `Work/`: GPT-6 Astra workers, one lemma group each. Verification of each returned proof (recompilation, search for `sorry`/`axiom`/`native_decide`, type identity with the original statement) and integration: the coordinating Claude session. No upstream file of the release is copied.
