# Start a proof unit

Copy `unit.json` and `correspondence.md` into `blueprint/units/YM-<issue>/`.
Place `section.tex` under the task's owned path in `manuscript/`; do not copy
this whole template directory into the blueprint. Replace all placeholders.
List the section and every local mathematical support file in `manuscript`.
Add its input to `manuscript/main.tex` within the claimed scope and build it.
Write the proof only in LaTeX. The correspondence record links its labels.
